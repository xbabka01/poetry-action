# Contributing

1. Fork the repository and create a branch from `main`.
2. Make your change. Pin any third-party action to a full commit SHA with a version comment,
   e.g. `uses: actions/setup-python@<sha> # v7.1.0`.
3. Open a pull request. The `Test action` workflow must pass on all OS / Python / Poetry combinations.

Pull requests are squash-merged, so the PR title becomes the commit message.
